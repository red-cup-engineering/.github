Organization defaults for issues and pull requests. Maintained by the GitHub engineering services section. Each service keeps its source in its own properly named repository and namespace. GitHub supplies an interface to the service’s original work and receiving process.

See [contribution guidance](CONTRIBUTING.md). These defaults apply only where a repository has no corresponding local template; local issue-template configuration takes precedence.
